**ERNativeUI 1.3.0 is the first release to publish ERUI API 1.3.**

This page is a visual tour of the release. For source changes, use the

## Custom System tabs

![A custom tab strip shifting through many client-provided tabs](https://raw.githubusercontent.com/Flammrock/ERNativeUI/ERNativeUI-v1.3.0/docs/assets/images/menus/custom-tabs-navigation.gif)

Client mods can now add their own top-level tabs to Elden Ring's System menu.
Each tab has a stable identifier, localizable title, and independent page
content, and can provide a custom RGBA8 icon. ERNativeUI combines registrations
from multiple mods, applies player-defined ordering, and keeps overflow tabs
reachable with native controller and mouse navigation.

[Create a custom tab](https://github.com/Flammrock/ERNativeUI/blob/ERNativeUI-v1.3.0/docs/guides/custom-tabs.md) ·
[Run the 50-tab stress example](https://github.com/Flammrock/ERNativeUI/blob/ERNativeUI-v1.3.0/examples/custom_tabs_stress/README.md)

## Title-screen text

![ERNativeUI text displayed in all four title-screen corners](https://raw.githubusercontent.com/Flammrock/ERNativeUI/ERNativeUI-v1.3.0/docs/assets/images/title-screen/title-screen-corners.png)

Client mods can add short version, status, or compatibility lines to any of
the four title-screen corners. A line can inherit Elden Ring's native color or
use an explicit RGB color. Placement adapts to the live title layout,
including the optional Shadow of the Erdtree line, and preserves text already
added by compatible mods.

[Add title-screen text](https://github.com/Flammrock/ERNativeUI/blob/ERNativeUI-v1.3.0/docs/guides/title-screen-text.md) ·
[Build the focused example](https://github.com/Flammrock/ERNativeUI/blob/ERNativeUI-v1.3.0/examples/title_screen_text/README.md)

## Runtime GFX completion and flexible tab capacity

ERNativeUI can now complete supported settings movies in memory as Scaleform
loads them. It expands Game, Camera, Display, Sound, Keyboard/Mouse, and
Graphics to 13 rows, Network to 10 rows, and preserves Advanced Graphics' 15
rows. It also supplies native TextInput and ColorPicker presentation without
installing loose replacement GFX files. Structurally compatible GFX supplied
by other mods remains supported, and players can turn runtime patching off
when they need the effective files left untouched.

The System tab strip still defaults to eight physical slots, but players can
request nine or ten through `MinimumTabSlots`. Larger logical tab collections
continue through the shifting and overflow navigation shown above.

[Understand runtime presentation and GFX compatibility](https://github.com/Flammrock/ERNativeUI/blob/ERNativeUI-v1.3.0/docs/guides/presentation-and-gfx.md)

## Compatibility and stability

API 1.3 capabilities were live-validated on Elden Ring executables 2.7.1.0 and
2.7.2.0. The retained 2.7.0.0 profile has reduced scope: API 1.0 through 1.2
paths remain available, but build-locked API 1.3 capabilities such as custom
tabs are unavailable. Custom-tab navigation was exercised with 50 registered
tabs, controller holds, mouse dwell, wrapping, rapid System-menu reopening,
and custom transparent icons.

[Check the exact compatibility matrix](https://github.com/Flammrock/ERNativeUI/blob/ERNativeUI-v1.3.0/docs/COMPATIBILITY.md)

## Moving from API 1.2

The 1.3 host retains the published API 1.0, 1.1, and 1.2 contracts, so existing
client binaries do not need to adopt API 1.3 merely to keep working. Use the
migration guide when a client wants to compile against the new surface.

[Migrate from API 1.2 to API 1.3](https://github.com/Flammrock/ERNativeUI/blob/ERNativeUI-v1.3.0/docs/migrations/1.2-to-1.3.md)
