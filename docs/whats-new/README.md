# What's new in ERNativeUI

What's New pages are visual overviews of the most important additions in each
feature release. They help players and mod authors discover new capabilities;
they do not replace the [changelog](../../CHANGELOG.md), the
[feature matrix](../features.md), or the source-focused
[API migration guides](../migrations/README.md).

| ERNativeUI release | ERUI API first published | Released | Visual showcase | Upgrade guide |
|---|---:|---:|---|---|
| 1.3.0 | 1.3 | 2026-10-20 | [What's new in 1.3.0](1.3.0.md) | [API 1.2 to 1.3](../migrations/1.2-to-1.3.md) |

ERNativeUI 1.3.0 is the first release with a dedicated What's New page. Future
entries will be added above it, while older pages remain available here as a
permanent visual history.
